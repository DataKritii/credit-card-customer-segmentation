# Data

`CC GENERAL.csv` is the *Credit Card Dataset for Clustering* (0.9 MB).

- Source: Kaggle, Arjun Bhasin, https://www.kaggle.com/datasets/arjunbhasin2013/ccdata
- 8,950 active credit card holders × 18 columns, summarising 6 months of card use.
- The currency isn't stated; amounts are treated as US dollars.
- If the file is missing, the notebook downloads a copy from GitHub.
